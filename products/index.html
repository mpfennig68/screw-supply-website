// CHOOSING A SYSTEM

Choose the security system by access and service needs

Security-drive selection begins with who should be able to install or remove the fastener. Pin-in 6-lobe, pin-in hex, two-hole spanner, and Tri-Groove systems all support authorized removal with a matching tool — none of them are correct for every application, and the right choice depends on the job.

One-Way screws and break-away nuts are generally selected where routine removal isn't expected, rather than where authorized service access is a priority. Thread form, head style, material, finish, installation environment, access, and future service requirements all factor into the decision alongside the drive system itself.

Whichever system fits your application, identify the matching installation and service tools when you select the fasteners — see the Drive Guide → to compare systems, browse fasteners by application →, or request a quote → if you'd like help matching a system to your job.

// COMPARISON

Comparing the security-drive options

  • Pin-In 6-Lobe →

    Hollow-tip six-lobe security tool engages around a center pin. Authorized removal supported. Machine, cap, sheet-metal, self-drilling, and masonry forms. Best where a familiar Torx®-style drive with broad size range is preferred.

  • Pin-In Hex →

    Hollow-tip hex security tool engages around a center pin. Authorized removal supported. Button, flat, socket, and cap forms. Best where a familiar hex/Allen format is preferred.

  • Two-Hole Spanner →

    Two-pin or two-prong tool engages matching holes in the head. Authorized removal supported. Machine and sheet-metal forms. Best for public fixtures needing periodic authorized service.

  • One-Way →

    Installs with a properly fitted flat-blade driver; ramped surfaces resist ordinary reverse engagement. Not intended for routine removal. Machine and sheet-metal forms. Best where disassembly isn't expected.

  • Tri-Groove →

    External socket fits over a rounded, grooved head. Authorized removal supported with the matching socket. Machine and sheet-metal forms. Best where a low-grip exterior profile is useful.

  • Security Nuts →

    Tri-Groove nuts use a matching socket for authorized removal; break-away nuts separate an installation section and aren't intended for routine removal. Best chosen by whether the joint needs future service.

// FAQ

Common questions

Which security-drive system should I choose?
Selection depends on who should be able to access the fastener, along with thread form, head style, material, finish, installation environment, and available tooling. No one drive system is correct for every application.
Which security fasteners allow authorized removal?
Pin-in 6-lobe, pin-in hex, two-hole spanner, and Tri-Groove systems normally permit authorized installation and removal with a compatible matching tool.
When should a One-Way screw or break-away nut be considered?
Both are generally selected where routine removal isn't expected. Removal is still possible, but future service typically requires specialized tooling or another planned method.
Do security fasteners require matching installation tools?
Yes. The tool has to match both the drive system and the size — a tool made for one drive system should not be assumed to fit another.
Can Screw & Supply help identify an unknown security fastener or tool?
Yes. Photographs, samples, part numbers, or drawings can help us identify an unknown fastener or the matching tool.
What information should I provide with a custom fastener inquiry?
Provide whatever you know — drive preference, thread form and size, head style, material, finish, quantity, application, and a drawing if available. We'll review what you send and follow up; we can't promise every custom request can be produced.

Not sure which security system fits the application?

Send us the application, any specifications you have, and photographs, samples, or drawings — we'll review it with you.
