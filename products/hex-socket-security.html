// FAQ

Common questions

Will an ordinary Allen-style key fit?
A solid-tip key cannot seat around the center security pin. Use a hollow-tip security hex tool matching the drive size listed for the part.
Are thread size and hex-drive size the same?
No. Thread size identifies the screw, while drive size identifies the tool. Use the separate drive column rather than choosing a key from thread diameter alone.
Which materials are listed?
The catalog tables below cover 18-8 stainless steel and alloy steel with black oxide, grouped by head and screw form. Confirm availability of the exact configuration.
How do I choose between cap and sheet-metal screws?
Cap screws use a matching tapped hole or nut. Sheet-metal screws engage the receiving material differently; specify the substrate, thread requirement, length, and head clearance.
Can you review custom sizes or materials?
Yes. Send a drawing or sample information with the thread, length, head style, material, finish, quantity, and any documentation requirements. We offer custom-manufactured fasteners with competitive minimum order quantities.
